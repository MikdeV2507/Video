## Content brief

**Learning objective:** after this episode the viewer can explain why racks are placed in a
hot aisle / cold aisle arrangement, and can check a row layout for correct orientation,
grid alignment and clearances.

**Three key points**
1. All racks in a row face the same way; rows face each other front-to-front and back-to-back.
2. Align rows to the floor grid so the cold aisle gets full perforated tiles.
3. Plan clearances for service and egress first — then fill the space with racks.

**Don't / Do:** a "classroom" layout (all rows facing the same direction, hot exhaust blowing
into the next row's intake) versus the alternating hot/cold aisle layout.

**Standards referenced:** TIA-942, EN 50600-2-3 (environmental control), ASHRAE TC9.9, local fire code.

**Pronunciation:** CRAH = "cray"; ASHRAE = "ash-ray".
